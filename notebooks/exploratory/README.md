# Exploratory notebooks

These are development and exploration notebooks from the course project that
produced this work. They are retained for reference and history but are **not**
maintained, may contain machine-specific paths, and may not reflect the final
pipeline.

For reproducing the paper's results, use the scripts in [`../../analysis/`](../../analysis/)
(authoritative) or the maintained notebooks in [`../`](../).

Contents (roughly): early minimum-viable-product implementations (`MVP_*`),
single-qubit RCS studies, the two-qubit gate and 12+1-layout explorations, a
noise-channel demonstration (`MVP_noise`), and a superseded earlier version of
the amplitude-comparison notebook
(`google12_tetron_vs_google_amplitudes_statevector_v1`). The
`srctetron_supremacy_MBQC_microsoft.ipynb` and `supremacy_MBQC_microsoft.ipynb`
files are two distinct variants that previously lived in `src/tetron/` and the
repo root respectively.
